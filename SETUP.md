# Running this locally

Everything except installed dependencies is in this archive. `node_modules`,
`.next`, and `lava_frontend/.env.local` were left out; the first two are
regenerated by the commands below and the third is machine-specific.

## Frontend

```bash
cd lava_frontend
cp .env.example .env.local     # then set LAVA_NETWORK and NEXT_PUBLIC_BACKEND_URL
npm install
npm run dev                    # http://localhost:3001
```

Requires Node 20+ (built and verified against Node 24.19.0 LTS, npm 11.17).

Routes:

| Path        | Contents |
|-------------|----------|
| `/`         | Marketing landing page, served statically from `public/landing.html` via a `beforeFiles` rewrite in `next.config.mjs`. Ships its own WebGPU hero, importmap, and ES modules, so it is deliberately not a React page. |
| `/stake`    | Mint and redeem, stats, integrations, auditors, FAQ |
| `/earn`     | Coming soon (built-out version preserved in `src/components/earn/`) |
| `/points`   | Points program, rates, estimator, wallet balance |
| `/portfolio`| Holdings |

`/vaults` was removed. Its components remain in `src/components/vaults/` and
`src/components/WorldMap.tsx` if it is ever restored.

Note: `npm run build` and `npm run dev` share the `.next` directory. Running a
build while the dev server is live causes intermittent `PageNotFoundError`
failures. Stop the dev server first.

## Backend

```bash
cd lava_backend
cp .env.example .env           # MAESTRO_API_KEY, JWT_SHARED_SECRET, TABLE_NAME, ...
npm install
npm run local:api              # http://localhost:5050
```

The frontend expects the backend at `NEXT_PUBLIC_BACKEND_URL`. Without it the
tables render empty, which is the intended empty state rather than an error.

## Smart contracts

```bash
cd smart_contract
aiken check
aiken build
```

Eight cooperating validators targeting Plutus v3, plus the per-integration
`stake_datums/` and `swap_validators/` modules. `plutus.json` is the compiled
blueprint. Unchanged from the original repository.
